### 证据采集工具链修正（重要）

无头截图的默认「整视口」路径在**模拟视口高于真实窗口表面**时会返回**未完成帧**：`position: fixed` 的合成层
（例如 `#mobileDock`）整体缺失，据此会得出"移动端没有底部操作坞"的错误结论。第一轮 52 张基线截图因此作废。
修正方式：改用 CDP `Page.captureScreenshot` 的**分带 clip** 逐带（≤300px）抓取 + sharp 拼接，并在每带底部注入
洋红哨兵像素断言该带确实已渲染；73/81 张截图经此校验通过（`capture.complete`），其余在重试后通过。
所有结论均以"DOM 几何 + 修正确认后的截图"双重证据为准。

### r1 — 桌面编辑器页脚 / 预览重影 / 阅读模式层级

  `var(--bg-panel)`，侧栏预览补 `border-left`；预览层恢复"覆盖源码"的上游语义。
- **UA-02 + UA-03 页脚错位与遮挡**：`.editor-foot` 水平内边距改为与 `.editor-scroll`/`.content-scroll-area`
  同一套 `max(16px, calc((100% - var(--content-max-width)) / 2))`；右侧额外保底 60px，为右下角浮动按钮

- **UA-16 `hidden` 失效 + CodeMirror 高度翻倍**：新增 `.editor-pane[hidden], .analysis-pane[hidden]{display:none}`，
  恢复 `hidden` 语义（首帧不再出现"编辑+分析"各占一半的布局）；并在 EasyMDE 创建后追加一次
